# 페이커 키우기 (가칭) — Pixel Esports Career Sim

첨부 기획서를 바탕으로 제작한 **모바일 우선 웹게임 MVP**입니다. 기존에 생성한 픽셀 아트 7종의 경기장/선수/배경을 잘라 사용하고, 스탯과 이벤트·버튼을 동작하는 HTML/CSS/JavaScript UI로 구현했습니다. 화면 안의 수치와 계약은 **실제 LoL 선수·구단의 기록이 아닌 게임 데이터**입니다.

## 실행 방법

**Node.js 20 이상**이 필요합니다. 외부 npm 패키지는 사용하지 않습니다.

```bash
npm install
npm run dev
```

로컬 주소: `http://localhost:5173` (변경하려면 `PORT=5174 npm run dev` 등으로 실행)

```bash
npm test
npm run build
npm run preview
npm run simulate -- 100   # 밸런스 자동 플레이 100판
```

## Vercel 배포

1. 이 폴더의 **파일과 폴더 전체**를 GitHub 저장소 최상위에 업로드합니다. (프로젝트 폴더가 한 단계 더 감싸지지 않게 주의)
2. Vercel → **Add New → Project** → GitHub 저장소를 선택합니다.
3. Framework Preset: **Other** / Root Directory: `./` / Build Command: `npm run build` / Output Directory: `dist` / Install Command: 기본 설정(의존성 없음).
4. **Deploy** 클릭. `.vercel` 설정이나 백엔드, 환경변수, DB는 필요하지 않습니다.

`vercel.json`에 정적 빌드 설정이 포함되어 있습니다. **Docker나 Vite, 데이터베이스는 필요 없습니다.**

## 구현 범위

- 7개 핵심 화면: 타이틀, 선수 생성, 메인, 랜덤 이벤트, 경기 결과, 이적 시장, 은퇴 결산
- 추가 화면: 승격 테스트, 명예의 전당, 게임 가이드
- 포지션 5개 및 포지션별 승률 가중치, 시작 능력치 +5 두 항목
- 기본 스탯 5개와 관리 스탯 4개, 훈련 4종, 부상에 따른 훈련 잠금
- 1시즌 8주, 1년 2시즌, 17세 시작, 나이에 따른 능력 성장 보정/하락
- 솔로랭크 10판 일괄 시뮬레이션 / 7개 티어 / LP 승급·강등
- JSON으로 관리되는 이벤트 21개와 선택지 requires 조건 / 일부 선택의 부상 위험
- 연습생 → 2군 → 1군 승격 테스트와 시즌 종료 계약 시장
- 가상의 LCK 구단 10팀 기반 제안 / 연봉 / 계약 기간 / 계약 종료 시 무제안 은퇴
- 통산 성적·명예의 전당·은퇴 진로·자동 저장·저장 기록 JSON 내보내기/가져오기
- 모바일 대응 / PC 중앙 정렬, 접근 가능한 기본 버튼과 명확한 상태 표시


## 설계/밸런스 관련 주의

- 기획서의 가중치 승률 공식과 LP 범위는 구현했습니다. 상대 전투력, 이벤트 출현 확률, 승격 확률, 팀 경기, 계약 제안 개수, 시장가치의 세부 나이 감점 및 연봉 금액 등 **기획서에 구체적인 확정 수치가 없는 항목은 플레이 가능한 MVP를 위한 임시 밸런스**입니다. 실제 플레이 테스트 후 조정하세요.
- 기획서의 7개 티어(아이언·브론즈·실버·골드·마스터·그랜드마스터·챌린저)를 따랐습니다. 이는 실제 LoL 전체 티어 체계와 다릅니다.
- 결승/우승 횟수는 2군/1군 시뮬레이션 성적 및 추첨을 통해 간략히 부여됩니다. 실제 리그 토너먼트 시스템을 구현한 것은 아닙니다.
- 원본 디자인은 픽셀아트 이미지입니다. 이를 단순 스크린샷 버튼으로 쓰지 않고, 실제 인터랙션은 HTML로 재구현했습니다.
- 저장은 브라우저 `localStorage`를 사용하므로 다른 기기와 자동 동기화되지 않습니다. 브라우저 데이터 삭제 시 진행 상황을 잃을 수 있습니다.
- 저장 데이터는 버전 1을 대상으로 하며, 이후 업데이트 시 저장 데이터 마이그레이션이 필요할 수 있습니다.

## 선수/게임 상표와 공개 배포

이 프로젝트에는 **실존 선수 이름을 모티브로 한 픽셀 이미지, e스포츠 팀명·로고를 연상시키는 이미지, LCK/LoL 관련 텍스트**가 포함됩니다. 해당 권리자의 공식 제휴·승인을 받았다는 의미가 아닙니다. 공개 배포/상업화를 할 예정이면 선수 초상권·퍼블리시티권, 구단/게임 상표 및 관련 라이선스 정책을 확인하고, 필요한 경우 오리지널 명칭/로고/캐릭터로 교체하세요. 생성된 로고나 인물 외형이 원본과 정확히 일치한다고 보장할 수 없습니다.
